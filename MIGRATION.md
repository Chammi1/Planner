# Перенос данных из старого HTML

Не удаляйте старый файл и не очищайте браузер до проверки импорта. JSON содержит личные данные: храните его приватно.

1. Откройте старый локальный HTML в том же браузере и по тому же пути, где вводились записи.
2. В старой версии нет кнопки экспорта. Откройте инструменты разработчика → Console. Введите команду ниже, только если понимаете её назначение: она читает локальное сохранение и скачивает JSON, сетевых запросов не делает. Не отключайте защиту браузера ради вставки непроверенного кода.

```javascript
const raw = localStorage.getItem('my-tasks-v1');
if (!raw) throw new Error('В этом хранилище данные не найдены');
const url = URL.createObjectURL(new Blob([raw], {type: 'application/json'}));
const link = document.createElement('a');
link.href = url;
link.download = 'planner-local.json';
link.click();
setTimeout(() => URL.revokeObjectURL(url), 1000);
```

3. Откройте серверное приложение и войдите. Нажмите «Импорт JSON», выберите файл, проверьте количество дел/отметок и подтвердите замену. Это НЕ объединение. Перед импортом приложение автоматически скачивает прежнюю серверную копию в JSON; также сервер хранит последние 50 ревизий.
4. Дождитесь «Сохранено на сервере», обновите страницу и проверьте данные. Затем проверьте в Telegram.

Файл tools/export-local.html — вспомогательный. Он видит только собственный origin; при file:// рядом лежащие HTML могут иметь отдельные хранилища. Поэтому для локального старого файла надёжнее экспорт из его собственной консоли.

Проект поддерживает максимум 500 дел, 50000 отметок и около 1,9 МБ JSON. Более крупный импорт сначала требует изменения лимитов и проверки нагрузки.
