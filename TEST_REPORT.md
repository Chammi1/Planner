# Проверки сборки

В среде подготовки выполнены:
- Синтаксический разбор всех Python-файлов.
- 14 unit-тестов: проверка HMAC Telegram, срок и пользователь, дублирующиеся поля, совместимость старого времени, относительные блоки, циклы, неверные интервалы/статусы/настройки и зарезервированные ID. Все прошли.
- Проверка синтаксиса JavaScript интерфейса и утилиты экспорта через Node.
- Smoke-проверка запуска JS с имитацией DOM/API: сессия, загрузка состояния, дневной календарь, метрики и карточка истории. Это не настоящий браузерный тест.
- Разбор Compose YAML, проверка отсутствия опубликованных портов у API/БД, проверка публикации только TCP 80 и 8443. Это не проверка `docker compose config` на реальном сервере.
- Проверка shell-скриптов через sh -n.

НЕ выполнены: сборка контейнеров с загрузкой зависимостей, проверка FastAPI/PostgreSQL в работающем стеке, выпуск сертификата, реальная авторизация Telegram, открытие Mini App в Telegram-клиентах, визуальная проверка, нагрузочное тестирование, аудит безопасности, тест восстановления реальной БД. Эти шаги нужны при развёртывании.
